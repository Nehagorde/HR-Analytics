# HR Analytics Dashboard

## Project Overview
This project focuses on analyzing employee data using Microsoft Excel to understand workforce trends, employee attrition, hiring patterns, and department performance. The dashboard transforms raw HR data into meaningful insights to support data-driven decision-making.

## Objectives
- Analyze employee attrition and employee exits.
- Track hiring trends and workforce distribution.
- Understand employee demographics by gender and country.
- Evaluate department-wise employee distribution.
- Monitor employee headcount and salary costs.
- Support workforce planning through data analysis.

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas and functions
- Data cleaning and data visualization
- KPI development

## Key Performance Indicators (KPIs)
- Total Employee Headcount
- Employee Attrition Rate
- Total Employee Exits
- Hiring Trends
- Salary Cost per Employee
- Department-wise Workforce Distribution
- Gender and Country Demographics

## Key Features
- Interactive HR dashboard for workforce analysis.
- Department-wise attrition analysis.
- Employee demographic insights.
- Hiring and termination trend analysis.
- Salary cost tracking and KPI monitoring.

## Dataset
The repository includes an Excel dataset used for HR data analysis and dashboard development.

## Project Outcome
This project demonstrates practical skills in Excel, data cleaning, data visualization, KPI tracking, and analytical thinking to derive actionable insights from HR data.
